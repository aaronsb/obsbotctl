# Protocol documentation

This directory will hold the protocol specifications as they're documented:

- **XU packet format** — 60-byte payload structure across the UVC extension
  unit selectors
- **Camera control service** — command framing and argument schemas
- **AI service** — tracking, auto-framing, gimbal, gesture commands
- **System management service** — for WiFi-equipped models
- **Event vocabulary** — async notifications

Empty for now. Documentation gets written here once each area is verified
against owned hardware.
